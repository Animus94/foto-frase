# foto-frase

Web app para celular (PWA) donde el usuario captura una foto con la cámara y le arma una frase combinando fragmentos predefinidos. Incluye un backoffice para administrar esas frases y moderar los envíos. Sin base de datos propia — pensada para hostearse 100% en GitHub Pages.

Ver [`CLAUDE.md`](./CLAUDE.md) para la arquitectura completa y el flujo de trabajo de los agentes de desarrollo.
